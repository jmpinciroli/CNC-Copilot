# CNC Copilot

## Descripción

Aplicación multiplataforma (Android, iPhone y Web) orientada a programadores CNC.

El sistema permitirá generar automáticamente programas en código G a partir de formularios guiados, evitando la programación manual.

---

# Objetivos

- Reducir tiempos de programación.
- Estandarizar programas CNC.
- Disminuir errores de programación.
- Facilitar la capacitación de nuevos programadores.
- Centralizar bibliotecas de herramientas y materiales.
