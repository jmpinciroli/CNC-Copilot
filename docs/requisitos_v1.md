# CNC Copilot

## Objetivo

Generar programas CNC automáticamente a partir de formularios guiados.

## Máquinas

- Torno CNC
- Centro de Mecanizado CNC

## Controles Iniciales

- Fanuc
- Haas

## Operaciones Torno

- Refrentado
- Cilindrado
- Ranurado
- Tronzado
- Roscado G76

## Operaciones Centro de Mecanizado

- Planeado
- Ranurado
- Bolsillos
- Taladrado
- Roscado

## Biblioteca de Herramientas

- Insertos de torneado
- Herramientas de ranurado
- Herramientas de roscado
- Fresas
- Brocas
- Machuelos

## Biblioteca de Materiales

- SAE 1018
- SAE 1045
- SAE 4140
- AISI 304
- AISI 316
- Aluminio 6061
- Fundición

## Salidas

- Código G
- PDF
